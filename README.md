## 📖 About This Repository

This repo documents my journey to **mastering C#** — one concept, one project, one commit at a time.

Each folder is a self-contained lesson: a runnable console app demonstrating a specific concept, with notes on *what* it does and *why* it matters. The goal isn't just "I wrote code that compiles" — it's building the kind of fundamentals that show up in real interviews and real production code.

> 💡 If you're a recruiter or hiring manager: this repo is a live log of how I learn, structure code, and document my work — not just a finished portfolio piece.

## 📁 Project Structure

\`\`\`
Mastering-CSharp/
│
├── 001 - Hello World/       # Console app: first program, basic syntax
├── Mastering-CSharp.sln      # Solution file
├── Mastering-CSharp.csproj   # Project file
├── Program.cs                 # Entry point
├── .gitignore
└── README.md
\`\`\`

Each numbered folder follows the same pattern:
- **Code** — a clean, runnable example
- **Comments** — explaining the *why*, not just the *what*
- **Notes** (where relevant) — key takeaways, gotchas, and links to docs

## ▶️ Getting Started

Clone the repo and run any lesson locally:

\`\`\`bash
git clone https://github.com/srinidhi8747/Mastering-CSharp.git
cd Mastering-CSharp
dotnet run
\`\`\`

> Requires the [.NET SDK](https://dotnet.microsoft.com/download) installed locally.

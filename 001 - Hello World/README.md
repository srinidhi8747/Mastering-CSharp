# 👋 001 - Hello World

> **Level:** Beginner  
> **Language:** C# (.NET)

---

## 🎯 Problem Statement

Write a C# program to display the message **"Hello, World!"** on the console.

---

## 📖 Description

This is the first and most basic program in C#. It demonstrates how a console application executes and how text is displayed using the console.

---

## 🧠 Concepts Covered

- Console Application
- `Console.WriteLine()`
- Class
- Method
- Entry Point (`Program.cs`)

---

## ▶️ Expected Output

```text
Hello, World!
```

---

## 📚 Learning Outcome

After completing this program, you will understand:

- How a C# console application works.
- How to print text to the console.
- The purpose of a class and a method.
- The basic execution flow of a C# program.
